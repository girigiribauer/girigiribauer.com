FlyFree Glide

Bluesky から X (Twitter) へワンクリックでクロスポストができるブラウザ拡張機能

FlyFree Glide は、Bluesky から X (Twitter) への同時投稿を支援し、徐々に新しい SNS への移行を促すためのブラウザ拡張機能です。 以前公開していた「FlyFree」の後継版として、Bluesky 側の公式ウェブクライアントをメインにしつつ X にも投稿したい方に最適です。

使い方・機能

ワンクリックでクロスポスト

拡張機能をインストールし、Bluesky の公式ウェブクライアントを開きます。 Bluesky で投稿を作成し、投稿ボタンを押すだけで X の投稿画面へ自動転送されます。画像を含む投稿も対応しています。

共有ボタンから後追い投稿

すでに Bluesky に投稿済みの内容も、シェアメニューから後から X に送信可能です。 先に Bluesky へ投稿して、後から必要に応じて X に投げた方がいいかどうか判断しながら使うことができます。

チラ見せモード

Bluesky の元投稿にリンクを貼りつつ、文章を途中でぶった斬る機能です。 「続きは Bluesky で！」が容易にできて、フォロワーを Bluesky へ誘導することができます。

X に蓋をするモード

「もう私は移行済みなんだ！ X なんてアイコンすら見たくもない！」という方向けに、モードを ON にすると X に関する一切の項目が画面から消えてなくなります。 これで平穏を手に入れつつ Bluesky で自由に飛びましょう！
