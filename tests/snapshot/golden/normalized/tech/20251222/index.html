Bluesky Advent Calendar 2025 の 22 日目の記事です。

ずいぶん昔にクロスポストツールを作りました

X(Twitter) から Bluesky への移行促進のために、以前 FlyFree というクロスポストツールを作りました。

ただ、まだ改善すべき箇所が色々と残っている状態だったのですが、 人生いろいろありまして、 ちょっとスイッチがオフになったままずるずるとここまで放置してしまいました。

人生いろいろあるよね。しょうがないね。

ありがとうアドベントカレンダー

アドベントカレンダーが作られたのをチラッと見かけて、 「もしかしてアップデートするなら今しかないのではないだろうか」 と考え、 アドベントカレンダー駆動開発 で11月の終わりから少しずつ重い腰を上げて、作業をしてきました。

審査通してアップデート 🎉

FlyFree - Chrome Web Store A crosspost tool for SNS to Fly Free! chromewebstore.google.com

わーい久々に審査通せたよー 🙌

12/22のアドベントカレンダーの記事にも間に合ったー！（ちょっとやばかったーw）

今回直したところ

直したというか、もはや作り直したと言っていいほど、内面は違うものになりました。（外見はほぼ変わってません）

  • 投稿中にタイムアウトが動かなかったケースを修正
  • 投稿失敗しても、入力したものがサルベージできるように投稿後画面にコピペUIを追加
  • アイコンが古かったのを新しいものに差し替え
    • リリース当時は Bluesky のアイコンすらまだなかったので、自作の雲アイコンでした…
  • 画像が投稿できないことがあるケースの修正
  • 必要以上に圧縮されていた画像の画質改善
  • 最近閉じたりするときに謎ポップアップが出るのを強制削除
  • 多言語対応（おおよそオプション画面）
  • その他コードの構成全部見直し

諦めたところ

  • Firefox 対応（改修範囲が広がりそうだったため断念）
  • たいっつー対応
    • 投稿APIが全然実装されそうにないのでもう無理そうです
  • OAuth 対応
  • その他たくさん

すまんな、もう地獄の方を見たくないんじゃあ。

今後の展望

あれだけ放置していたのにも関わらず、意外に思われるかもしれませんが、 実は自分、このツールほぼ毎日使ってます。

Bluesky にだけ投稿するという使い方が意外と便利なんですよ。 ニュース記事を雑に見てポストするのがいい感じに便利です。

ですが、すでに見ていない X(Twitter) の intent URL を利用しているせいで、 実は X(Twitter) の障害の影響を受けてしまう ことに、この前気づきました。

見てもいないサービスに影響受けるってどういうことじゃー！

という気持ちになったため、この FlyFree をこのまま使っていくのは危険 と判断し、 こちらをメンテナンスバージョンにしつつ、 似たUIで Bluesky にだけ投稿できる次世代版 を用意していこうと思います！

そしたら色々諦めたところもやれちゃうかもね！ 遅くならないうちに作りまーす！
